# 13F Smart-Money Rollup
Use when asked to compare top institutional manager behavior across two quarters.

## Preserve factuality
If an authoritative ranked Top 30 list is not available, do not invent names. Summarize entrants, exits, and largest holders by:
- real-world manager
- ticker
- direction (new buy / add / sell / full exit)
- "why" when publicly stated

## Sources
- Primary: WhaleWisdom latest filings + analysis
- Secondary: MacroMicro sector-oriented 13F views
- Tertiary: fund-specific news summaries

## Output shape
1. Quarter-over-quarter changes (additions, reductions, full exits by sector/ticker)
2. Apparent reasoning or stated strategy shifts if disclosed
3. Aggregate sentiment shift (buyers vs. sellers, sector rotation)

## Pitfalls
- 13F has a 45-day reporting lag; for matched comparisons use established filers where available
- "Top 30" lists may not exist in a single authoritative ranked form; use true evidence rather than inferring rank
- Some sources are paywalled; prefer the best publicly available evidence over fabricated rankings
