# Design Handoff Boards

Class-level skill for the full pipeline that turns `frames/NN_Name.html` into importable Figma boards. Complements `html-to-figma-import-safety` (bypass catalog) with the **generation + merge + delivery** workflow proven on D.A.R. Dental (75 frames).

## Pipeline

1. **Generate** — `gen_frames.py` writes one `frames/NN_Name.html` per screen, all `390×844`, `display:flex;flex-direction:column`, `overflow:hidden`. No `absolute`/`transform`/`rgba`/`content:`.
2. **Order** — `frames/order.txt` is the deck manifest (`# Section` + `NN_Name`). Merge follows deck order, labels renumbered by position. Never filename-sort.
3. **Merge** — `merge_frames.py frames/ -> DAR_Dental_All_75.html`:
   - Parse `--x: value;` from first frame CSS, resolve `var(--x[,fallback])` in CSS + per-frame HTML (char class `[a-z0-9-]+`, not `[a-z-]+`).
   - Inline every `<use href="#i-*>` (match `ic` AND `icon` classes), inject `viewBox` attrs when missing, strip hidden sprite per frame.
   - Extract `.frame` div only (regex `(<div class="frame".*?</div>)\s*</body>`), never leak trailing `</body>`.
   - Inter-frame connectors: **real SVG polygons, not border triangles**. `.conn { display:flex; flex-direction:column; align-items:center }` + `<div class="conn-stem">` + `<svg width="10" height="6"><polygon points="0,0 10,0 5,6"/></svg>` (deck) or `14×14` for flow graphs. Border-triangle `.arr { width:0;height:0; border-... }` is zero-size and the importer drops it — connectors import stem-only.
4. **Flow graph** — `flow_board.py` renders the 2D navigation map (cluster boxes, elbow connectors with real `<polygon>` arrowheads, dashed = 12px rects). Same var/icon inlining.
5. **Wireframes** — Rebuilt by appending `!important` gray `:root` override to the freshly merged boards, not by editing copies. `All -> Wireframe`, `Flow -> Flow_Wireframe` in one pass.

## Import-safety asserts (end of every merge/flow script)

```python
assert "var(" not in doc
assert "<use" not in doc and "<symbol" not in doc
assert "rgba(" not in doc
assert "repeating-linear-gradient" not in doc
assert "<a " not in doc
assert doc.count("<polygon") > 20  # deck ~65/75, flow >100 (169 observed)
```

## Wireframe append pattern

```python
wire_extra = """
<style>
:root{ --accent:#8a8f98 !important; ... --st-cancelled-bg:#e9eaee !important; }
.banner,.notif,.tag,.chip,.pill,.datebox,.kpi,.banner.warn,.banner.err { background:#ffffff !important; border-color:#d1d5db !important; color:#6b7280 !important; }
.tag.owner,.tag.staff,.chip,.pill { background:#e9eaee !important; color:#6b7280 !important; }
</style>"""
Path("Wireframe.html").write_text(src.replace("</head>", wire_extra + "\n</head>", 1).replace("<title>Merged frames</title>", "<title>Wireframe</title>"))
```

## Verification (deterministic before vision)

- `audit.py` — CSS braces, tag balance, unresolved icons, import-safety negatives, hardcoded colors, story grep, browser overflow + `390×844` geometry.
- `qa_shot.py` — `75/75 OK`, `scrollHeight <= 844`, `maxBottom <= h`, `fill >0.75`, contact sheets.
- `qa_deep.py` — no squished buttons (`h<34`), no x-overflow, `body.scrollHeight <= clientHeight`.

## Single-frame Figma-safety (when frames already exist, no merge)

Merge-time inlining (step 3) only runs inside `merge_frames.py`. When individual `frames/NN_*.html` are hand-edited or generated by another tool, sanitize each frame standalone before import — same negatives, same fixes. Reusable routine: `references/per-frame-figma-safety.md` (run as `python - << 'PY'`). It resolves `var()`, inlines `<use href="#id">` from the sprite, strips `<symbol>`/sprite block, converts `rgba()` scrims to hex, and rewrites `<a>` to `<div>`. Apply to every frame the user will import individually.

## Pitfall — preview boards: iframes, never extraction

For a *preview* board that shows several frames at once, embed with `<iframe src="frames/NN_Name.html">` inside fixed `390×844` `.phone` boxes. **Do NOT** extract the `.frame` div out of each frame and inline it into the board (as `merge_frames.py` does for the *import* board) — the extracted HTML still carries `var()`/icon refs that the board's CSS doesn't define, so styles silently vanish and the board renders blank. The session hit this three times (`Income_Grouped.html` shrank to ~1900 chars, blank render). Rule: **Figma imports the individual `frames/` files; the board is preview-only, so iframes are correct and extraction is the bug.** Only `merge_frames.py` (which fully inlines) produces an importable single-file board.

## Pitfall

Stale boards: `DAR_Dental_All_71.html` lingered after adding staff sections J/K (47-54) and order.txt changes. Importing it produced missing staff column. Always delete stale `All_*.html` after regenerating, or assert `n_labels == n_frames == len(order_entries)`.
