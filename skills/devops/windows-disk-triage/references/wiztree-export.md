# WizTree CLI export — verified reference (v4.31, Aug 2026)

## Working command
```bash
"/c/Program Files/WizTree/WizTree64.exe" 'C:\' '/export=C:\Users\YOUR_USERNAME\AppData\Local\Temp\wiztree.csv' /admin=1 /exportfolders=1 /exportfiles=1
```
Syntax from https://diskanalyzer.com/guide:
`wiztree64.exe "drive/folder" /export="filename" [/admin=0|1] [/exportfolders=0|1] [/exportfiles=0|1] [/filter=...] [/sortby=...]`

## Failure modes seen (each cost a run)
1. **No positional drive arg → silent no-op, no file, exit 0.** The drive/folder MUST come first.
2. `/exportfolders=PATH` (wrong usage, it's a 0|1 flag) → nothing.
3. `/admin=1` from bash: parent bash exits immediately ("DONE") — the **elevated child** (2+ GB RAM, MFT scan) keeps running and writes the file ~30–60s later. Don't trust the shell command's completion.
4. Elevated child **locks the CSV while writing**: `cp` → "Device or resource busy", python open() → PermissionError. Wait for `tasklist | grep -i wiztree` to show only the idle GUI (or nothing) before parsing.
5. Non-elevated shell **cannot taskkill the elevated child** — wait, don't fight it.
6. `/admin=0`: no UAC but does a slow directory walk (5+ min on this machine and still running) — only if UAC is impossible.
7. Old zombie WizTree GUI processes linger after `process kill` of the bash wrapper — harmless, killable with `taskkill //IM WizTree64.exe //F` (they don't elevate).

## Export CSV layout (utf-8-sig, CRLF, all fields quoted)
- Row 1: banner `Generated by WizTree 4.31 ...` (skip)
- Row 2: header `File Name,Size,Allocated,Modified,Attributes,Files,Folders,DRIVECAPACITY,FREESPACE,USEDSPACE,RESERVEDSPACE`
- Data rows (index): **0**=path (quoted), **1**=Size bytes, **2**=Allocated, **3**=Modified `YYYY MM DD HH:MM:SS`, **4**=Attributes int, 5/6=file/folder counts
- **Directory rows end with `\`** — that's the reliable dir test; the Attributes int is NOT (folders show 2/6, not 16)
- Root row carries DRIVECAPACITY/FREESPACE/USEDSPACE → free-space truth without df
- Sample: `"C:\$AV_AVG\",899917926,899928064,2024 03 02 17:33:58,2,7,1`
- Size: 476 GB drive ≈ 880 MB / 5,086,000 rows; python csv module parses in ~60s (utf-8-sig!)

## Parse
Use `scripts/wiztree_parse.py` in this skill. If you need custom queries, reuse its row-handling (skip len<7 rows, int(row[1]), endswith('\\') = dir).

## Nice extra
The Modified column gives the "what landed a few days ago" answer directly — filter files >100MB modified since the user's date window, then match against the uninstall registry (`Get-ItemProperty HKLM:\...\Uninstall\* | Sort InstallDate`) and session history for the story.
