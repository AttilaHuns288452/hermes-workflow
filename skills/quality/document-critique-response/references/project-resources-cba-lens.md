# Project Resources CBA lens — defense notes

The lens: resources CONSUMED by the project vs economic benefits/resources gained. Not a private financial return to the clinic. Classification rules below keep a revision defensible without overcorrecting.

## What counts as a project resource cost
- Donated development labor counts at its economic value even though the clinic pays no cash. State it as a cash-expenditure vs economic-cost distinction; do not remove it because no invoice exists.
- Keep the development labor total consistent with the itemized breakdown (total = sum of task rows). Itemize tasks in hours so the total is auditable.
- Hourly-rate assumptions: a labeled, below-market internal rate carried forward consistently is defensible on its own terms. Do not manufacture external sources to "prove" a rate; state it as the project's own rate-card assumption and keep it identical everywhere it appears.
- Deployment/hosting/dataset items are real project resources when they consume project effort or money. Renaming a category is a change — only do it on the five grounds.

## What counts as a benefit
- Released staff time is a valued labor resource (capacity released), NOT a payroll cash saving, unless cash savings are evidenced. Describe it as capacity released and say explicitly that no payroll reduction is claimed.
- Recovered revenue: acknowledge gross vs net where incremental consumable costs attach to recovered activity; keep the gross figure as the measured benefit and disclose the qualifier.
- Benefits measured in staff-hours must reconcile with the narrative (e.g. hours per year vs "hours per day" claims — convert and align them).

## Cash-flow tables and payback
- Separate the cash-expenditure view from the total economic-cost view; label which is which.
- Payback wording: "costs are recovered in X" means cumulative net >= 0. Cross-check: payback years x annual net ≈ investment.
- When there are multiple cost tiers (e.g. recovery-only scenario), name the tier inside the payback sentence — an unlabeled payback next to a different tier's table is misleading.
- Payback on a projection year = that year's annual net, not a cumulative or ramped figure; state the basis.

## Projection honesty
- Discount rate: if zero, say nominal totals are undiscounted and state what discounting would do directionally.
- FX and escalation assumptions: one value everywhere; an inconsistency between the narrative and tables is a fix (ground 4).
- Scope line: which costs are project resource use vs routine business costs the clinic already bears (e.g. internet/electricity) — list the excluded ones so the boundary is explicit.
