## Quick Selection Rules

- Default narration → `cross arms stnading front.png` (neutral pose, versatile)
- Split screen comparisons → `handing hand to the left...` + `...right` mirrored
- Shocking stat → `shocked.png`
- Kicker / punchline → `thumbsup.png` or `openarms.png`
- Warning / bad debt → `hand on chin thinking.png`
- Good outcomes → `holding cash.png` or `holding laptop.png`
- Direct address / hook → `pointing at the viewer.png`
