# Example 15-Question Quiz — Anime Personality Match

This is a production-ready question set. Adapt the theme, answer text, and modifiers
for your own quiz. Each question targets 1-3 personality axes.

## Design Principles

1. **15 questions is the sweet spot** — long enough for accuracy, short enough to finish
2. **4 answers per question** — enough variety without overwhelming choice
3. **Each answer modifies 2-3 axes** — prevents single-axis stacking
4. **Mix of axis coverage** — every axis gets probed ~6-10 times across all questions
5. **Fun, relatable language** — speak the audience's language (anime references, memes, etc.)
